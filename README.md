# Gcode Layer Editor

`index.html` をダブルクリックしてブラウザーで開いてください。インストール・通信・サーバーは不要です。

## 操作

1. 左の「1層〜8層」で編集対象を選びます。緑色が選択層です。「選択した層だけ表示」で単独表示できます。
2. 輪郭形状、寸法、中心、回転、高さ間隔、線種を設定し、「変更をモデル・G-codeに反映」を押します。層を切り替えると、入力中の変更も反映します。無効な値は反映されません。
3. 「＋ 最上部に層を追加」は、選択層にかかわらず最上層の上に追加します。輪郭・線種・寸法・高さ間隔・停止時間を直下の層から引き継ぎます。位相反転はオン／オフできます。
4. 「初期モデル・全体の操作」内の「モデル全体を消去」で全層・全線・G-codeの移動命令を消去します。「元に戻す」または ⌘/Ctrl+Z で復元できます。
5. 「G-code出力」で保存します。この版が出力したG-codeには層の設定を含むため、「G-codeを開く」で再編集できます。ページを再読み込みすると初期モデルに戻るので、作業後は保存してください。

狭い画面では3D図面・G-code・層編集が縦に並びます。上部の「層編集へ」で編集欄へ移動できます。

## 輪郭と線種

- 輪郭：角丸四角形、四角形、楕円／円、多角形、自由な多角形。多角形の幅と奥行を同じにすると正多角形になります。
- 自由な多角形：「図面で輪郭を描く」で図面上を3点以上クリックし、「輪郭を確定」で閉じます。座標欄に1行ずつ `X, Y` を入力することもできます。自己交差・辺同士の接触は入力エラーになります。
- 三角形：底辺、高さ、底辺の両端で止まる時間、0〜180°の位相を指定できます。「正三角形に固定」をオンにすると高さを自動計算します。停止時間はms（1000 ms＝1秒）で、共有する底辺頂点では1回だけ停止します。開始位置と終端が底辺なら、それぞれ到達・出発時にも停止します。
- Sinカーブ：波長、山〜谷の高さ、位相を指定。振幅は山〜谷の高さの半分です。停止命令は出力しません。
- 三角形／Sinの方向：垂直は基準Zから上向き、水平は輪郭から外向きです。どちらも変位は0〜指定高さ。位相0°は谷、180°は山を輪郭の始点に置きます。
- 直線：平面上の輪郭を1周します。
- 塗りつぶし：輪郭を1周し、設定した間隔・角度で内部を往復します。凹形状では内部の各区間に分割し、間の移動は押出しなしで行います。

閉じた輪郭では、継ぎ目に不連続ができないよう1周の波数を整数にし、底辺／波長を均等に微調整します。入力値に最も近い波数と実際の寸法を編集欄に表示します。正三角形の寸法は輪郭を展開した面での値であり、角丸部分では曲がった輪郭に沿います。

## 高さと初期モデル

第1層はプレートからの高さ、第2層以降は直下の層の**基準Z**からの高さ間隔です。間隔を変えると、それより上の層も移動します。上部設定の「高さ」は樹脂線の断面厚みで、層同士の間隔とは別です。

初期モデルは8層、60×60 mmの角丸四角形（中心90,90／半径10 mm）、垂直の正三角形、位相0°・180°交互です。第1層の基準Zは0.5 mm、以後の間隔は4 mm、底辺指定は5.5 mm、停止時間は500 msです。追加は最大128層です。

元の添付G-codeには、1周の中で高さが徐々に変わる軌跡や上下面の異なる軌跡があり、G4停止命令はありませんでした。そのため、この初期モデルは今回の指定を基にした編集用モデルで、元の軌跡と完全一致するものではありません。「元のG-codeを表示」で元データを開けます。元データは `original-sample.gcode` にも保存してあります。

G-codeを直接編集したり既存の一括設定を適用した場合は、その変更を表示します。「層設定からG-codeを再生成」を押すと、直接編集した線を含むG-code全体を層設定から作り直します。層設定がない外部G-codeの輪郭を自動推定する機能はありません。

## 出力と確認範囲

Bambu向け3MF出力、温度検査、所要時間推定に対応しています。層間・塗りつぶし区間間の移動は、それまでの軌跡の最高Zより2 mm上へ上がってからXY移動します（機体のZ上限まで）。G0移動も描画・時間計算・再計算の対象に修正しています。

軌跡の数値検証、ブラウザー操作、G-code保存の復元、3MFのパッケージ内容を確認済みです。実機造形とBambu Studioでの読み込みは未検証です。ノズル本体の干渉、層同士の接触や支持、造形の成立性は自動判定しません。

## 手入力の一括反映・再検査（2026-09-12更新）

- ノズル径・線幅・線の高さ・Flowを手入力し、「一括反映（線幅・E・温度・速度）」を押してください。推奨値で上書きせず、**入力値**からEを計算します。`GCODEEDITOR_MODEL`、各層の`LINE_WIDTH`・`LAYER_HEIGHT`、既存の設定ブロックも同期します。
- 樹脂線断面積は幅w≧高さhの場合 `A = h(w−h) + πh²/4`。3D移動距離Lに対し `ΔE = L×A×Flow / (π×1.75²/4)` です。たとえば線幅0.5、高さ0.2、Flow0.98なら100 mmの線にE約3.7246 mmを使います。ノズル径自体を断面積として使うのではなく、線幅・高さを使います。
- 流量表示は `Q = A×速度×Flow`。一括反映はG0/G1のXYZ移動に伴う正の押出しを再計算し、絶対／相対E・G92 Eリセットを扱います。Eだけのパージ／リトラクト量・速度は保持します。一括反映を繰り返してもEは二重に増減しません。
- 「再検査・修正」は修正候補を項目ごとに表示します。**YES**でその項目を修正、**NO**で保持します。推奨寸法、入力値とEの差、流量に対する速度、温度命令・待機、開始・終了条件を確認します。Eの差は1%または0.00003 mmを超えるものをまとめて提示します。
- **NOでも3MFを出力できます。** 出力時に推奨値へ戻したりE／速度／温度を再修正することはありません。確認事項はレポートに残ります。未反映の層入力・空モデル・数値として成立しない入力は先に解消してください。
- 手入力をG-codeへ適用する操作は一括反映です。3MF出力だけを押しても、未適用の寸法やEを自動変更しません。

## プレートと第1層の検査

選択したA1 mini（180×180×180 mm）、A1／P1S（256×256×256 mm）の造形範囲を使います。ノズル径と線幅の大きい方の半径を余白に含め、外周とP1Sの除外領域（X0〜18、Y0〜28 mm）との干渉を確認します。中央への移動で解決できる場合は移動を提案し、寸法の縮小が必要な場合は具体的な手動修正を案内します。

第1層の最低Zと入力した樹脂線の高さに差があると、押し潰し過多／浮きの可能性を示します。YESで全体をZ移動し、上層同士の間隔を保持します。添付画像のような最低Z0.15 mm・線の高さ0.2 mmでは、+0.05 mmの移動を提案します。Bambu標準プロファイルの第1層高さ（ノズル0.2／0.4／0.6／0.8 mmに対し0.1／0.2／0.3／0.4 mm）も参考表示します。

第1層が上下に動く非平面軌跡なら連続した接地面がないことを示し、平面塗りつぶしへの変更を提案します。塗りつぶし間隔が線幅より広い場合も確認します。これらの輪郭再生成は全層の設定から行うため、直接編集済みのG-codeには自動適用しません。数値検査だけで実際のプレート凹凸・Zオフセット・定着状態・ノズル本体の干渉は確認できません。

検査基準の参考：Bambu Studio公式の [A1 mini](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20A1%20mini%200.4%20nozzle.json)、[A1](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20A1%200.4%20nozzle.json)、[P1S](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20P1S%200.4%20nozzle.json)、[標準プロセス](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/process/fdm_process_common.json)。0.4 mmノズルの標準プロセスにも第1層線幅0.5 mmがあり、0.42 mmとの不一致だけで出力を禁止するものではありません。機種の寸法・除外領域は公式設定、流量安全率・第1層の判定許容差などは本アプリ内の検査目安です。

## SVGの輪郭読み込み

「平面上の輪郭」→「SVGファイルから輪郭を読み込む」でSVGを選択します。複数の図形がある場合は使用する輪郭を選び、読み込み幅をmmで指定して「この輪郭を層の入力欄へ」→層の「反映」を押します。選択層だけが変わります。

閉じたpath（ベジェ曲線・円弧）、polygon、閉じたpolyline、rect、circle、ellipse、およびSVGのtransformに対応します。縦横比を保持して指定幅へ拡縮し、現在の中心XYへ配置します。SVGの上下方向を補正し、上面図の向きを保ちます。曲線は1536点までの直線近似で、読み込み後は自由な多角形として編集・保存・上層への複製ができます。

穴を含む複合path、入れ子SVG、文字、画像、use参照には対応しません。複合pathはSVG側で別々のpathに分割してください。1層に設定するのは選択した1つの閉じた輪郭です。2 MB・200図形まで、輪郭は最大2048頂点。開いた線・自己交差は適用できません。SVGのスクリプトや外部画像は実行／読み込みません。

## 開発用

`editor-base.html` は添付エディターの保存コピーです。追加機能は `layer-engine.js`、`layer-ui.js`、`layer-panel.html`、`layer-panel.css`、`process-review.js`、`review-panel.html`、`svg-import.js` に分けています。

```sh
python3 build.py
node --test tests/*.test.cjs
```

`build.py` で単独動作する `index.html` を再生成します。
