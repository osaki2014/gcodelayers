# Gcode Layer Editor

`index.html` をダブルクリックしてブラウザーで開いてください。インストール・通信・サーバーは不要です。

## 操作

1. 左の「1層〜8層」で編集対象を選びます。緑色が選択層です。「選択した層だけ表示」で単独表示できます。
2. 輪郭形状、寸法、中心、回転、高さ間隔、線種を設定し、「変更をモデル・G-codeに反映」を押します。層を切り替えると、入力中の変更も反映します。無効な値は反映されません。
3. 「＋ 最上部に層を追加」は、選択層にかかわらず最上層の上に追加します。輪郭・線種・寸法・高さ間隔・停止時間を直下の層から引き継ぎます。位相反転はオン／オフできます。
4. 「初期モデル・全体の操作」内の「モデル全体を消去」で全層・全線・G-codeの移動命令を消去します。「元に戻す」または ⌘/Ctrl+Z で復元できます。
5. 「G-code出力」で保存します。この版が出力したG-codeには層の設定を含むため、「G-codeを開く」で再編集できます。ページを再読み込みすると初期モデルに戻るので、作業後は保存してください。

狭い画面では3D図面・G-code・層編集が縦に並びます。上部の「層編集へ」で編集欄へ移動できます。

## 輪郭と線種

- 輪郭：角丸四角形、四角形、楕円／円、多角形、自由な多角形。多角形の幅と奥行を同じにすると正多角形になります。
- 自由な多角形：「図面で輪郭を描く」で図面上を3点以上クリックし、「輪郭を確定」で閉じます。座標欄に1行ずつ `X, Y` を入力することもできます。自己交差・辺同士の接触は入力エラーになります。
- 三角形：底辺、高さ、底辺の両端で止まる時間、0〜180°の位相を指定できます。「正三角形に固定」をオンにすると高さを自動計算します。停止時間はms（1000 ms＝1秒）で、共有する底辺頂点では1回だけ停止します。開始位置と終端が底辺なら、それぞれ到達・出発時にも停止します。
- Sinカーブ：波長、山〜谷の高さ、位相を指定。振幅は山〜谷の高さの半分です。停止命令は出力しません。
- 三角形／Sinの方向：垂直は基準Zから上向き、水平は輪郭から外向きです。どちらも変位は0〜指定高さ。位相0°は谷、180°は山を輪郭の始点に置きます。
- 直線：平面上の輪郭を1周します。
- 塗りつぶし：輪郭を1周し、設定した間隔・角度で内部を往復します。凹形状では内部の各区間に分割し、間の移動は押出しなしで行います。

閉じた輪郭では、継ぎ目に不連続ができないよう1周の波数を整数にし、底辺／波長を均等に微調整します。入力値に最も近い波数と実際の寸法を編集欄に表示します。正三角形の寸法は輪郭を展開した面での値であり、角丸部分では曲がった輪郭に沿います。

## 高さと初期モデル

第1層はプレートからの高さ、第2層以降は直下の層の**基準Z**からの高さ間隔です。間隔を変えると、それより上の層も移動します。上部設定の「高さ」は樹脂線の断面厚みで、層同士の間隔とは別です。

初期モデルは8層、60×60 mmの角丸四角形（中心90,90／半径10 mm）、垂直の正三角形、位相0°・180°交互です。第1層の基準Zは0.5 mm、以後の間隔は4 mm、底辺指定は5.5 mm、停止時間は500 msです。追加は最大128層です。

元の添付G-codeには、1周の中で高さが徐々に変わる軌跡や上下面の異なる軌跡があり、G4停止命令はありませんでした。そのため、この初期モデルは今回の指定を基にした編集用モデルで、元の軌跡と完全一致するものではありません。「元のG-codeを表示」で元データを開けます。元データは `original-sample.gcode` にも保存してあります。

G-codeを直接編集したり既存の一括設定を適用した場合は、その変更を表示します。「層設定からG-codeを再生成」を押すと、直接編集した線を含むG-code全体を層設定から作り直します。層設定がない外部G-codeの輪郭を自動推定する機能はありません。

## 出力と確認範囲

既存のBambu向け3MF出力、温度検査、ノズル変更時の押出し量補正、所要時間推定を引き継いでいます。層間・塗りつぶし区間間の移動は、それまでの軌跡の最高Zより2 mm上へ上がってからXY移動します（機体のZ上限まで）。G0移動も描画・時間計算・再計算の対象に修正しています。

軌跡の数値検証、ブラウザー操作、G-code保存の復元、3MFのパッケージ内容を確認済みです。実機造形とBambu Studioでの読み込みは未検証です。ノズル本体の干渉、層同士の接触や支持、造形の成立性は自動判定しません。

## 開発用

`editor-base.html` は添付エディターの保存コピーです。追加機能は `layer-engine.js`、`layer-ui.js`、`layer-panel.html`、`layer-panel.css` に分けています。

```sh
python3 build.py
node --test tests/*.test.cjs
```

`build.py` で単独動作する `index.html` を再生成します。
